# Prompt Pack

## 1) PRD Prompt
"Create a product PRD for a meal decision app for India urban households. Include personas, jobs-to-be-done, user stories, acceptance criteria, and non-functional requirements. Keep MVP in 8-10 weeks."

## 2) Recipe Schema Prompt
"Design a recipe schema for breakfast/lunch/dinner/snack with fields for diet mode, prep/cook time, spice level, ingredients with quantity, and step-by-step instructions. Include regional cuisine tags."

## 3) Recommendation Algorithm Prompt
"Design a rules-based meal recommendation algorithm that takes diet preference, day-wise rules, meal slot, time budget, exclusions, and recent history, then returns 1 primary + 2 alternatives with anti-repetition scoring."

## 4) UX Copy Prompt
"Generate bilingual (English + Hindi) microcopy for onboarding, suggestion CTA, swap flow, and weekly planner for a household cooking assistant."

## 5) QA Prompt
"Create a QA checklist for meal planning MVP including mixed-diet households, exclusions, invalid profile data, empty recipe sets, and weekly planner edit edge-cases."
