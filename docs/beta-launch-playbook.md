# Beta Launch Playbook

## Cohort Setup
- Batch A: 100 households (friends/community leads).
- Batch B: 400 households from creator + community channels.

## Feedback Loops
- In-app quick rating after each suggestion.
- Weekly 5-minute NPS survey.
- WhatsApp support channel for bug reports.

## Experiment Backlog
1. Suggestion copy variant A/B.
2. Weekly plan auto-fill order.
3. Swap button prominence.
4. Theme default (light vs dark).

## Weekly Review Cadence
- Monday: bug triage + roadmap update.
- Wednesday: recommendation quality review.
- Friday: retention cohort review + release.

## Exit Criteria for Public Launch
- Crash-free sessions > 99%
- Suggestion success ("I cooked this") > 35%
- D30 retention > 15%
